# API Contract

MedGuide AI is medication assistance software. The API does not diagnose, prescribe, recommend
dosage, or claim certainty about a medication. AI endpoints return safety-first wording that must
be shown to users.

Base path: `/api/v1`

Authentication: protected endpoints require `Authorization: Bearer <access_token>`.

Standard error envelope:

```json
{
  "error": {
    "code": "validation_error",
    "message": "Request validation failed",
    "request_id": "request-id",
    "details": []
  }
}
```

Common error status codes: `401` unauthenticated, `403` forbidden, `404` not found or not linked,
`409` conflict, `422` validation error, `503` provider or dependency unavailable.

## Auth APIs

`POST /auth/register` public, `201`

```json
{
  "email": "pat@example.com",
  "password": "Use-a-strong-password-123",
  "full_name": "Pat Patient",
  "role": "PATIENT",
  "timezone": "America/Chicago",
  "accessibility_preferences": {}
}
```

Response:

```json
{ "access_token": "...", "refresh_token": "...", "token_type": "bearer" }
```

`POST /auth/login` public, `200`

```json
{ "email": "pat@example.com", "password": "Use-a-strong-password-123" }
```

`POST /auth/refresh` public, `200`

```json
{ "refresh_token": "..." }
```

`POST /auth/logout` public, `204`

```json
{ "refresh_token": "..." }
```

`GET /auth/me` protected, `200`: returns the current active user without password hashes.

## Medication APIs

All medication endpoints are protected. Patients can manage their own medications. Caregivers need
an active link with sufficient permission. Admin is not a default ownership bypass.

`GET /medications`, `200`: list active, non-deleted medications.

`POST /medications`, `201`

```json
{
  "name": "ExampleMed",
  "generic_name": null,
  "brand_name": null,
  "dosage": "10 mg",
  "form": "TABLET",
  "instructions": "User-confirmed label text only.",
  "source": "MANUAL",
  "active": true
}
```

`GET /medications/{medication_id}`, `200`

`PATCH /medications/{medication_id}`, `200`

`DELETE /medications/{medication_id}`, `204`: soft delete.

OCR-sourced medication drafts must not become active until confirmed by the patient. The API stores
instructions as user-confirmed text only.

Protected.

`POST /schedules`, `201`

```json
{
  "medication_id": "uuid",
  "frequency_type": "DAILY",
  "scheduled_time": "09:00:00",
  "days_of_week": null,
  "interval_hours": null,
  "start_date": "2026-06-05",
  "end_date": null,
  "reminder_offset_minutes": 0,
  "active": true
}
```

`GET /schedules`, `200`

`GET /schedules/today`, `200`

`PATCH /schedules/{schedule_id}`, `200`

`DELETE /schedules/{schedule_id}`, `204`: deactivates the schedule and preserves historical dose
logs.

## Dose Log APIs

Protected. Dose logs are generated by the backend and are never hard deleted by the client.

`GET /dose-logs`, `200`

`GET /dose-logs/today`, `200`

`PATCH /dose-logs/{dose_log_id}/confirm`, `200`

```json
{
  "confirmation_method": "BUTTON",
  "actual_taken_time": "2026-06-05T14:00:00Z",
  "notes": null
}
```

`PATCH /dose-logs/{dose_log_id}/skip`, `200`

```json
{ "notes": "Patient chose to skip." }
```

`PATCH /dose-logs/{dose_log_id}/needs-help`, `200`

```json
{ "notes": "Caregiver follow-up requested." }
```

## Caregiver APIs

Protected unless noted. Caregiver access is always scoped to active links.

`POST /caregivers/invite`, `201`: patient invites a caregiver.

```json
{
  "caregiver_email": "caregiver@example.com",
  "relationship": "Daughter",
  "permission_level": "VIEW_ONLY"
}
```

`POST /caregivers/accept`, `200`: authenticated caregiver accepts an invite.

```json
{ "invite_token": "one-time-token" }
```

`GET /caregivers/patients`, `200`: caregiver lists linked patients.

`GET /caregivers/patients/{patient_id}/today`, `200`: schedules and dose logs for a linked patient.

`GET /caregivers/patients/{patient_id}/dose-logs`, `200`: linked patient dose history.

`PATCH /caregivers/links/{link_id}/revoke`, `200`: patient revokes access.

## Upload APIs

Protected. Uploaded images are private. Responses return image IDs and signed URLs only; public
bucket URLs and object keys are not exposed.

`POST /uploads/signed-url`, `201`

```json
{
  "purpose": "MEDICATION_LABEL",
  "content_type": "image/jpeg",
  "size_bytes": 123456
}
```

Response:

```json
{
  "image_id": "uuid",
  "upload_url": "https://storage-provider/upload",
  "upload_fields": { "key": "signed-field" },
  "expires_in_seconds": 300
}
```

`GET /uploads/{image_id}/signed-read-url`, `200`

`DELETE /uploads/{image_id}`, `204`: deletes provider object, then soft-deletes the image record.

## AI Scan And Verify APIs

Protected. AI results are assistance only and must be displayed with the returned safety message.
Missing provider credentials in production return a safe `503`; the API does not fabricate OCR or
vision output.

`POST /ai/scan-label`, `200`

```json
{ "image_id": "uuid" }
```

Response:

```json
{
  "result": "LABEL_READ",
  "ocr_text": "raw text",
  "extracted_fields": { "name": "ExampleMed", "dosage": "10 mg" },
  "confidence_score": 0.82,
  "requires_confirmation": true,
  "safety_message": "Please confirm the extracted medication information before saving."
}
```

Never auto-save OCR output. Users must confirm or edit extracted fields first.

`POST /ai/verify-medication`, `200`

```json
{
  "dose_log_id": "uuid",
  "image_id": "uuid",
  "verification_type": "PILL_VERIFY"
}
```

Response:

```json
{
  "result": "MATCH_UNCERTAIN",
  "confidence_score": 0.7,
  "requires_confirmation": true,
  "safety_message": "I am not fully sure this appears to match your scheduled medication. Please check the label again or contact your caregiver."
}
```

The backend compares only against the user's currently due medication. It does not identify pills
universally and does not decide medical action on behalf of the user.

## Device Notification APIs

Protected.

`POST /devices`, `201`

```json
{ "platform": "IOS", "push_token": "ExpoPushToken[...]" }
```

Response omits the push token:

```json
{
  "id": "uuid",
  "platform": "IOS",
  "active": true,
  "created_at": "2026-06-05T00:00:00Z",
  "updated_at": "2026-06-05T00:00:00Z"
}
```

`DELETE /devices/{device_id}`, `204`: deactivates the device token for the authenticated user.

## Privacy APIs

Protected.

`GET /privacy/export`, `200`: exports the current user's scoped data without password hashes,
refresh tokens, push tokens, signed URLs, or raw sensitive provider secrets.

`DELETE /privacy/images/{image_id}`, `204`: deletes a private image and prevents future signed
read URLs.

`POST /privacy/revoke-caregiver/{link_id}`, `204`: privacy-focused caregiver revocation endpoint.
